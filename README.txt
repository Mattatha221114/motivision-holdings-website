## Current Functionality

- Responsive layouts for desktop, tablet, and mobile.
- Expandable Services and Resources menus.
- Animated hero graphics across all pages.
- Varied page transitions and hover effects.
- An About page with the company photograph, story, and timeline.
- Mobile bottom navigation with a central WhatsApp button.
- Floating call and WhatsApp buttons.
- Support for reduced-motion preferences.

The enquiry form opens the visitor’s email application; it does not submit enquiries to a server. Client login remains under development. Resource guides marked as being prepared are not yet available.
